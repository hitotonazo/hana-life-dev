# 02. GAME FLOW / PHASE進行・異常演出

# 9. PHASE1

## 発生場所

`flowers.html` のダリア。

## 最初の異常

通常ダリア：

```text
flower-dahlia.jpg
```

原型株：

```text
prototype-dahlia.jpg
```

を約0.5秒ごとに繰り返し切り替える。

```text
通常色
↓ 0.5秒
真っ白な原型株
↓ 0.5秒
通常色
↓
繰り返し
```

これはプレイヤーが「表示不具合ではなく意図的な異常」と判断できる強さにする。

### 操作性

異常開始後は、現在どちらの画像が表示されていてもダリア画像／カードをクリック可能にする。

0.5秒の表示タイミングにクリック成功を依存させない。

## ダリアクリック後

ダリア画像を白方向へフェード。

その下に以下を表示。

```text
継続利用者評価区分

対象：継続利用者
評価項目：感情安定度
目標値：72％
運用状況：実施中
```

この時点では「人格改変」「洗脳」「催眠」等を明示しない。

## 次の操作

`継続利用者評価区分` をクリック可能にする。

クリック時：

```text
サイトが改変されました
```

既存modulesのサイト改変演出を実行。

完了後、PHASE2へ進行。

# 11. PHASE2 スクロール異常

使用する原型株：

```text
prototype-sweetpea.jpg
prototype-lavender.jpg
prototype-lily.jpg
prototype-jasmine.jpg
prototype-geranium.jpg
prototype-dahlia.jpg
```

スクロールして各花を通過すると、順番に通常画像から原型株画像へ変化。

```text
スイートピー
↓
ラベンダー
↓
ユリ
↓
ジャスミン
↓
ゼラニウム
```

### 状態保持

一度原型株へ変化した花は、上へスクロールして戻っても通常色へ戻さない。

PHASE2中の進行状態として保持する。

### 見せ方

原型株画像は、

- 植物全体が真っ白
- 暗いチャコール〜黒背景
- 研究記録の標本写真

である。

「通常の商品写真が内部管理用の原型株画像へ上書きされている」ように見せる。

# 12. PHASE2 最終ダリア

ページ下部到達時点：

- 1〜5段階：原型株へ変化済み
- ダリアのみ通常色

短い間を置いた後、ダリアを徐々に原型株へ変化させる。

可能であれば単純な一瞬の画像交換ではなく、

```text
通常色
↓
彩度低下
↓
茎・葉の緑が消える
↓
花芯・花弁の色が消える
↓
prototype-dahlia.jpg
```

という印象をCSS/画像クロスフェードで表現。

過剰に長くしない。

## ダリアクリック

完全に原型株へ変化したダリアをクリック。

以下を表示。

```text
第6段階　定着
系統番号：DL-06
誘導効果安定化個体
```

`第6段階　定着` をクリック。

```text
サイトが改変されました
```

既存modulesの改変演出後、PHASE3へ。

PHASE3到達後は `voices.html` へ自然に誘導／遷移させる。

# 14. PHASE3

PHASE3到達後、長期利用者レビューを異常状態へ変更。

## メイン異常

15〜20件程度の長期利用者レビューが、異なる名前・年齢・人物写真にもかかわらず、全員同じ文章。

```text
花のある生活が一番落ち着きます。
今の生活がとても好きです。
```

文章は完全一致させる。

## 人物画像

`review-human-01.jpg` ～ `review-human-16.jpg`

を使用。

写真は全員別人だが、長期利用者ほど、

- 白・ベージュ系の服
- 明るい髪
- 色の少ない背景
- 穏やかな表情

へ近づいているように配置する。

年齢と白色化が単純に連動して見えないよう、人物の並び順は調整してよい。

## 唯一の進行対象

レビューのうち1件だけ、

- 約2秒周期で赤み
- 短いノイズ
- 一瞬テキストが消える
- 写真が軽く乱れる

などの異常を出す。

重要なクリック対象はこの1件のみ。

過度な点滅は禁止。

クリック：

```text
サイトが改変されました
```

改変演出後PHASE4へ。

# 15. PHASE4 利用経過記録

PHASE4では、PHASE3でクリックした利用者の「利用経過記録」を表示。

5段階：

```text
利用開始前
3か月
6か月
12か月
18か月
```

使用画像：

```text
progress-human-00.jpg
progress-human-03.jpg
progress-human-06.jpg
progress-human-12.jpg
progress-human-18.jpg
```

## PC

5枚を視認しやすく配置。

画面幅に応じて、

- 5列
- 3+2
- 2+3

など自然に崩してよい。

## SP

必ず縦方向。

横スクロールで5枚を見る構成にはしない。

## 数値

後半に以下を表示。

```text
感情安定度 98％
嗜好一致率 94％
判断一致率 91％
人格一致率 96％
```

この時点では「基準人格」の詳細説明はまだ行わない。

# 16. PHASE4 最終異常

重要異常は「18か月」の写真。

通常は：

```text
progress-human-18.jpg
```

を表示。

約3秒ごとに、同じ枠内の人物を切り替える。

```text
convergence-human-01.jpg
convergence-human-02.jpg
convergence-human-03.jpg
convergence-human-04.jpg
convergence-human-05.jpg
```

人物は異なるが、

- 白い服
- 白〜プラチナ系の髪
- 穏やかな表情
- 同じような白い室内
- 同じ位置のダリア
- ほぼ同じポーズ

を維持。

「画像の位置はほとんど変わらないのに人物だけ別人になる」印象を作る。

## クリック後

18か月写真をクリック。

画面を暗くし、PHASE3で使用した複数の長期利用者写真を画面上に出す。

写真群が徐々に中央へ集まり、重なる／収束する演出。

中央に1枚の代表的な収束人物画像を残す。

表示：

```text
第6段階　定着完了
```

小さく：

```text
基準人格モデルとの一致を確認
```

中央画像をクリック。

```text
サイトが改変されました
```

改変演出後 `truth.html` へ。
