## 0. この文書の優先度

この文書は、STEP4以降の実装担当者へ渡すための**現行実装保護指示**です。

以下に「変更禁止」「維持」と記載された箇所は、STEP4の追加仕様を実装する都合だけで変更、削除、置換、再設計してはいけません。新機能は既存挙動へ影響しない形で追加してください。

仕様の衝突が見つかった場合は、独自判断で既存実装を上書きせず、作業を止めて依頼者へ確認してください。明示的な変更指示を受けた場合に限り、指定された範囲だけを変更できます。

## 1. 絶対に変更しない共通仕様

- 通常サイトのHeader、Footer、ロゴ、ナビゲーション構成
- PC/SPのハンバーガーメニューと、メニュー内スクロール
- 本文の基本文字サイズ、最小文字サイズ
- 深い角丸のボタン形状
- ボタンhover時の透過表現
- 白背景部分で使用している `images/paper.jpg`
- `modules/site-alteration` 本体
- 改変演出の表示文言「サイトが改変されました」
- 改変演出の多重再生防止
- 探索リセット処理と初期状態への復帰
- localStorageキー `whiteBloomArgProgress` による進行状態保持
- ページ移動、リロード、ブラウザバック後のPHASE状態復元

異常コンテンツ以外のページ全体を黒背景へ変更することは禁止です。Header、Footer、通常ページ見出し、通常説明領域は従来の明るいWHITE BLOOMの外観を維持します。黒背景・赤文字は、異常が発生している内部記録コンテンツに限定します。

## 2. デバッグモードの固定仕様

既存moduleを次の構成で使用しています。

- `modules/site-alteration/site-alteration.js`
- `modules/site-alteration/debug-panel.js`
- `window.SiteAlterationDebug.init(...)`

デバッグモードはURLへ `?debug=1` を付けて有効化します。

- `Alt + Shift + D`：デバッグパネルの表示／非表示
- `Alt + Shift + A`：site-alteration演出の再生
- パネル内：PHASE1〜PHASE4の切替

デバッグmoduleを独自実装へ置き換えないでください。デバッグ用UIを通常アクセス時に露出させることも禁止です。

## 3. PHASE1の凍結仕様

- 発生場所はHomeの「今月の花・ダリア」
- ダリアが一度画面内へ入り、その後画面外へ出た時点で異常を開始
- 通常ダリアと白い原型株を4秒ごとに切替
- 切替時にノイズと画像の揺れを表示
- ダリア画像のクリックで既存site-alterationを再生
- 演出完了後、自動的にPHASE2へ進行
- 「継続利用者評価区分」はクリック必須の進行ボタンではなく、改変後の確認資料
- PHASE2以降にHomeへ戻っても、ダリアの白い原型株と継続利用者評価区分を維持
- ダリアクリック後にFlowersへ自動遷移しない

PHASE3到達後などにHomeへ戻った際、ダリアを通常画像へ戻すことは禁止です。

---

## 4. PHASE2の凍結仕様

- 対象ページは `flowers.html`
- ページ見出しは通常の明るい背景を維持
- 黒背景は `.flowers-page` の内部記録領域に限定
- 「お届けする花」の見出しと内部記録の間には上部余白を設ける
- 6種類の花はスクロールに応じて順番に白い原型株へ変化
- ダリアには約2秒周期のノイズと揺れを表示
- ダリアの初回クリックでエラーポップアップを表示
- エラータイトルと説明文の間に余白を維持
- エラーを閉じた後、ダリアのコンテンツ全体を再クリックして進行
- 2回目のクリックでsite-alterationを再生
- 演出完了後にPHASE3を保存し、`voices.html` へ遷移
- 「季節の花を、暮らしの中へ。」は黒背景にしない

## 6. PHASE4／利用経過記録の凍結仕様

- 利用経過記録は `progress-human-00.jpg`〜`progress-human-05.jpg` の6枚を使用
- 存在しない `progress-human-06.jpg`、`progress-human-12.jpg`、`progress-human-18.jpg` を参照しない
- 18か月の枠はクリック可能
- 18か月の基本表示は `convergence-human-01.jpg`
- 3秒ごとに02、03、04、05の順で別人物を本当に一瞬だけ表示
- 別人物を常時表示したり、長時間切り替えた状態にしない
- 18か月のノイズ演出を維持
- 「利用者の声一覧へ戻る」ボタンを維持
- 戻るボタンではPHASE3の利用者記録一覧を再表示
- 再度PHASE3の異常カードからPHASE4へ進行可能
- 収束結果のクリック後は既存site-alterationを経て `truth.html` へ進む
